## 📋 Что было создано?

### 🎯 Основная функция: `/profile_visibility`

Команда для управления видимостью полей профиля пользователя.

**Параметры профиля, которыми можно управлять:**

- 📏 Зріст (Height)
- 🧍 Стать (Gender)
- 🎂 Вік (Age)
- ⚖️ Вага (Weight)
- 🎯 Мета (Goal)

**Как работает:**

1. Пользователь вводит `/profile_visibility`
2. Бот показывает меню с кнопками для каждого поля
3. Пользователь нажимает на кнопку, чтобы переключить видимость
4. Настройки сохраняются в БД
5. При просмотре `/profile` показываются только видимые поля
