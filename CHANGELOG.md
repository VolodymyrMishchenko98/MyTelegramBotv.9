# Changelog - История изменений

## [11.05.2026] - Profile Visibility Feature

### ✨ Новые функции

#### 1. **Модуль управления видимостью профиля** (`profile_visibility.py`)

- Новый независимый модуль для управления видимостью полей профиля
- Полностью разделена бизнес-логика от обработчиков команд

##### Функции в модуле:

- `get_profile_visibility()` - получить состояние видимости всех полей
- `toggle_field_visibility()` - переключить видимость поля
- `set_field_visibility()` - установить видимость поля
- `is_field_visible()` - проверить видимость конкретного поля
- `get_visible_fields()` - получить список видимых полей
- `get_field_label()` - получить метку поля для отображения
- `ensure_user_exists()` - убедиться в существовании пользователя

#### 2. **Команда `/profile_visibility`**

- Интерактивное меню для управления видимостью полей
- Отображает статус каждого поля (✅ видимо / 🚫 скрыто)
- Позволяет переключать видимость одним нажатием кнопки

#### 3. **Улучшенный ввод профиля**

- Лучшая валидация всех параметров:
  - Зріст: проверка диапазона (100-250 см)
  - Стать: поддержка разных форматов (ч/м/male/чоловік и ж/f/female/жінка)
  - Вік: проверка диапазона (1-120 лет), опциональный параметр
  - Мета: проверка на пустое значение

- Информативные сообщения об ошибках:
  - Точное указание причины ошибки
  - Подсказки по исправлению
  - Примеры правильного формата

- Автоматическое управление видимостью:
  - При создании профиля все поля видимы по умолчанию
  - После успешного сохранения предлагается настроить видимость

- Подтверждение и итоги:
  - Отображение всех сохраненных данных
  - Форматированное сообщение об успехе

### 🔧 Технические улучшения

#### Интеграция и рефакторинг:

- Добавлен импорт из нового модуля `profile_visibility.py` в `bot.py`
- Обновлена функция обработчика `profile_toggle` для использования `toggle_field_visibility()`
- Функция `ensure_user()` заменена на алиас к `ensure_user_exists()`
- Удалена дублирующаяся функция `get_profile_visibility()` из `bot.py`
